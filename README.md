# Ronin Engine

**Ronin Engine** is a C++ game engine project currently under development.

The project focuses on learning and implementing the fundamentals of game engine development, computer graphics, and low-level rendering using OpenGL.

## Project Goals

- Develop a deeper understanding of game engine architecture.
- Learn low-level graphics programming with OpenGL.
- Explore rendering pipelines and GPU communication.
- Build reusable engine systems using modern C++.
- Gradually develop a foundation for creating games.

## Technologies

| Technology | Purpose |
|---|---|
| C++23 | Core programming language |
| OpenGL | Graphics rendering API |
| GLFW | Window and input management |
| GLAD | OpenGL function loading |
| Clang | C++ compiler |
| GNU Make | Build system |
